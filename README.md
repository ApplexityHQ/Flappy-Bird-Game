# 🐦 Flappy Bird Arcade (Canvas + JS)

A retro-style **Flappy Bird clone** built from scratch using **HTML Canvas and Vanilla JavaScript**.

This project focuses on **core game development fundamentals** — no libraries, no frameworks — just pure logic, physics, and rendering.

> 🎮 Current Version: **V2.2**  
> 🤖 Next Step: **AI / ML-powered Flappy Bird**

---

## ✨ Features

- 🕹️ Retro arcade-style UI
- 🎬 Game states (Intro → Play → Game Over)
- 🐦 Custom bird character with physics & animation
- 🌱 Procedurally generated pipes
- 💥 Collision detection
- 🧮 Score system
- 🖱️ Keyboard & mouse controls
- 🎯 Beginner-friendly difficulty

---

## 🧠 Concepts & Learnings

This project helped me understand and implement:

- **HTML Canvas rendering**
- **Game loop** using `requestAnimationFrame`
- **Basic physics** (gravity, velocity, jump impulse)
- **Collision detection** (AABB)
- **Procedural generation** (pipes)
- **State-driven architecture** for UI & gameplay
- **UX iteration** for better game feel

---

## 🕹️ Controls

- **Space / Click** → Jump
- **Space / Click (on Game Over)** → Restart
